# huy-portfolio

Personal portfolio site for Huy Nguyen. Live at https://hiiamhuy.github.io/huy-portfolio/

Plain static HTML/CSS/JS — no build step. Edit `index.html` and `style.css`
directly; push to `main` to deploy via GitHub Pages (project Pages, served from
the repo root). All asset paths are relative so the site works under the
`/huy-portfolio` subpath.

- `resume.md` — resume source of truth
- `resume.pdf` — generated download (`pandoc resume.md -o resume.pdf`)
